# Volley Lens

小学校のソフトバレーボールの授業で使う、試合の記録とふりかえりのアプリです。
黒とグレーを基調にしたLiquid Glass風の画面で、得点・失点の理由を2タップで記録し、チームのよいところと次にがんばることを、小学6年生が読める丁寧な言葉で表示します。

**アプリを開く:** https://061-ttt.github.io/A/

## できること

- **記録:** 「得点」「失点」を押して理由を選ぶだけで記録できます。全員でつないだ得点の＋1点ボーナスにも対応しています。
- **取り消し:** ×ボタン、「1つ戻す」、お知らせの「取り消す」、行を左にスワイプ、のどれでも取り消せます。
- **分析:** 得点率、得点・失点の理由の内訳、「チームのよいところ」「次にがんばること」（それぞれ50字以上）、おすすめの練習、話し合いの問いかけを表示します。
- **試合の管理:** 試合ごとに記録を分けて保存し、一覧から開いたり削除したりできます。
- **保存:** 記録は端末のブラウザ内に自動で保存されます。JSONでのバックアップと読み込み、CSVでの書き出しができます。
- **アプリとして使う:** ホーム画面に追加でき、一度開いたあとはオフラインでも使えます。
- **アニメーション:** 記録したときの紙吹雪やスコアの動きなどがあります。端末で動きを減らす設定にしている場合は止まります。

## 授業での約束（アプリの前提）

3〜4人制、2バウンド可、キャッチして仲間に渡すのも可。これらは失点に数えません。

## プライバシー

児童の氏名・成績・健康情報は記録しない設計です。記録はその端末のブラウザの中にだけ保存され、外部には送信しません。

## テスト

実際のブラウザ（Chromium）で画面を操作するテストを、PC幅とスマホ幅（Pixel 7）の両方で実行します。

```bash
npm ci
npx playwright install chromium
npm test                                   # このフォルダを配信してテスト
BASE_URL=https://061-ttt.github.io/A/ npm test   # 公開中のサイトをテスト
```

`main` に push すると、GitHub Actions がテストを実行し、すべて合格したときだけ GitHub Pages に公開します。公開後は、公開サイトに対しても同じテストを実行します。
